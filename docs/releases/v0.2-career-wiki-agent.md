## Product Positioning

Career Wiki Agent is a local-first career preparation workspace. It helps users maintain structured career materials, map JD requirements to verified projects and skills, produce reviewable tailored resume drafts, and export final artifacts to an Obsidian vault.

The core product value is trust: final resumes should be useful for real applications without inventing project outcomes, leaking sensitive data, or hiding weak evidence.

## Safety Boundary

The project does not implement:

- Automatic job application
- Recruiting platform crawling
- Login automation
- HR messaging
- Cookie management
- Proxy pools
- Captcha bypass
- LinkedIn / BOSS / Zhilian automation
- Unconfirmed automatic sending

## Current Data Boundary

- Runtime data is local SQLite.
- Obsidian artifacts are written under `CAREER_VAULT_PATH`.
- API keys, cookies, tokens, private keys, and account credentials must never be exported, logged, or documented.
- ReviewFlow AI must remain described as WIP / prototype / semi-finished unless verified evidence changes that status.

## Production Quality Gap

The v0.2 line is functionally useful but still needs stronger operational controls:

- End-to-end workflow state visibility
- Audit logs for critical actions
- Evidence quality review beyond binary verified / draft / rejected status
- Operations health and integrity checks
- Backup commands
- Central sensitive-content guards across exports and logs
- E2E validation checklist

These gaps are addressed by the v0.3 production-quality consolidation.
