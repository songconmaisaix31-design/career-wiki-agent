## Safety Boundary

This release does not add:

- Automatic job application
- Recruiting platform crawling
- Login automation
- HR messaging
- Cookie management
- Proxy pools
- Captcha bypass
- LinkedIn / BOSS / Zhilian automation
- Unconfirmed automatic sending

## Approval Rules

- Draft resume versions cannot export final formats.
- Approved resume versions must pass the export checklist.
- Open high-severity Evidence Quality Review items block approval.
- Final resume text must not include sensitive credentials, `production-ready` overclaims, `Missing Evidence`, or unsupported ReviewFlow AI status claims.

## Validation

Required commands:

```bash
npx tsc --noEmit
npm test
npm run lint
DATABASE_URL=file:./dev.db npm run build
npm run career:healthcheck
npm run career:integrity
```

Integrity may return `warn` with exit code `0` when real-use data is incomplete, such as no verified evidence or no approved resume version. `fail` indicates a blocking tool or data issue.
